# Theme prototypes

The five looks that were tried for 0.3.0 before Houndstooth was chosen and built into the game (`src/index.css`, `tailwind.config.js`): `tweed` (the one that became Houndstooth), `parlour`, `fog`, `strand` and `casebook`. `themes.mjs` describes them, `css/` holds each one's styles, `build.mjs` builds a contact sheet and `shoot.mjs` photographs it with Playwright.

This is a record of the design, not part of the game or its tests. The contact sheets and screenshots are generated (13 MB) and are not kept: run `node build.mjs` then `node shoot.mjs` to make them again.
